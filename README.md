# RailBook

Indian railway ticket booking ka demo Android app (Kotlin + Jetpack Compose).

## Download
**Latest:** [RailBook-v1.0.2.apk download karein](https://github.com/pankajkatariya45-oss/RailBook/raw/main/RailBook-v1.0.2.apk)

Purana version: [v1.0.1](https://github.com/pankajkatariya45-oss/RailBook/raw/main/RailBook-v1.0.1.apk)

- Android 7.0 ya usse naya
- Install ke time "Install unknown apps" allow karein
- Purani RailBook ho to pehle uninstall karein

## Features
India ke 8,700+ stations (sabhi states/UTs, district-wise), kisi bhi route par demo trains,
Train search, seat availability (AVL/WL), passenger details, mock payment, 10-digit PNR, e-ticket,
cancel + wallet refund, aur Hindi/Hinglish AI travel assistant.

> Demo app hai. IRCTC se connected nahi hai aur asli ticket issue nahi karta.
